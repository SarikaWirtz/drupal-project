# Clone Project.

```bash
git clone git@github.com:SarikaWirtz/drupal-project.git
ddev start && ddev composer install
```

# Copy settings.local.php and Connect with your db here.

```bash
cp web/sites/example.settings.local.php web/sites/default/settings.local.php
```


**Getting started**

Once local enviorment is up and running.

Steps to add 'Slier' on your page.

1) Go to 'Create content'.
2) Select "Add content"-> Select 'Basic Page'.
3) Add page title.
4) Click on 'Add Paragraph' in 'Content Sections'.
5) Fill 'Title', 'Background Image' and 'Short text'.
6) Add Slides as many as you want.
7) Click 'save' and preview the page.
